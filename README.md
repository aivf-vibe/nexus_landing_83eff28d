# Nexus Landing Page

A modern landing page built with React, TypeScript, Vite, and TailwindCSS.

## Features

- React + TypeScript setup with Vite
- TailwindCSS for styling
- Responsive design
- Accessibility improvements
- SEO optimizations

## Development

This project uses Vite for development with HMR and ESLint rules.

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Run ESLint
- `npm run preview` - Preview production build
